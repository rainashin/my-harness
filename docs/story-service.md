## 유저스토리

| # | 유저스토리 | PRD 근거 |
|---|---|---|
| 1 | 여러 목표 영역을 관리하는 사용자가 이번 달 목표를 영역별로 등록하고 주차별 분량으로 나눈다. | 3-1 (US-01, US-02) |
| 2 | 매일 접속하는 사용자가 이번 주와 오늘의 미완료 할 일을 먼저 확인하고, 할 일을 추가해 주차별 목표에 연결한다. | 3-2 (US-03, US-04) |
| 3 | 할 일을 완료한 사용자가 한 번의 완료 처리로 주간·월간 목표 실적이 바뀌는 것을 확인한다. | 3-3 (US-05) |
| 4 | 한 주를 점검하는 사용자가 목표별 계획량·완료량·남은 양을 비교하고, 미완료 할 일을 다른 날짜나 다음 주로 옮긴다. | 3-4 (US-06) |
| 5 | 여러 영역을 병행하는 사용자가 월간 화면에서 영역과 주차를 비교해 지연되거나 방치된 목표를 찾는다. | 3-5 (US-07) |

## 제외한 항목

- **전월 목표 구조 복사 (US-08):** 복사 범위가 PRD에서 미확정이라 이번 목록에서 제외했다.
- **사용자별 데이터 분리 (7장):** 금지 규칙 후보였으나 위 2개를 우선했다.
