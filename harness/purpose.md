# 하네스 목적

작성일: 2026-09-30
기준 문서: story-service.md(판정 기준), story-work.md(작업 흐름), design.md(디자인 가이드), prd.md(입력)

## 매번 달라지는 것

- PRD 버전
- 대상 화면 목록: 1~4개. 주간 현황, 월간 현황, 목표 생성·수정, 태스크 보기 중에서 고른다.
- 고정: design.md, story-service.md

## 사용자

- 실행: 본인(디자이너 1인)
- 결과 컨펌: 본인이 직접 한다.

## 결과물 위치

- Figma 파일 1개. 페이지 구성은 다음과 같다.
  - 00_Gate Log: 게이트마다 결과 프레임 1개(통과 여부, 날짜, 규칙별 위반 개수)
  - 01_Reference: 레퍼런스 10개
  - 02_Screen Spec: 화면 설계 A안·B안
  - 03_Design: 디자인 시안 A안·B안

## 완료 기준

레퍼런스 10개, 화면 설계 2종(A·B안), 디자인 시안 2종(A·B안)이 Figma에 있고,
Gate Log에 게이트 2개의 통과 프레임이 있으며, 가이드 위반이 0개이고,
본인의 컨펌이 1회 기록되어 있다.
